Supabase Setup Guide

  1. Log in to supabase.com and create a project.
  2. Go to the left menu: SQL Editor -> + New query.
  3. Click COPY SQL button above, paste it in the query box, and click Run.
  4. Go to Project Settings -> API, copy your Project URL and anon public key, paste them on the left and click Save & Connect.
  5. Click SYNC PRODUCTS TO SUPABASE to immediately push all catalog items!
